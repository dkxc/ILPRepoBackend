## Overview
The PUT API for updating trainee details (Endpoint #26) already includes full 
support for updating the trainee status field. This feature is fully implemented 
and operational.

## Endpoint Details

**URL**: PUT /api/Trainees/{id}
**Description**: Update trainee details including status
**Parameters**: id (integer) - Trainee ID

## Request Body (Including Status)

```json
{
  "id": 1,
  "email": "john.doe@example.com",
  "phoneNo": "1234567890",
  "status": "Active",  // ? Status field is supported
  "bloodGroup": "APositive",
  "aadhaarId": "123456789012",
  "healthCondition": "Good",
  "personalInterest": "Programming",
  "address": "123 Main St",
  "currentAddress": "456 Current St",
  "contactNumber": "9876543210",
  "emergencyContactName": "Jane Doe",
  "emergencyContactRelationship": "Spouse",

```

## Supported Status Values

The `status` field accepts the following values from the `TraineeStatus` enum:
- **Active**: Trainee is actively participating in the program
- **Inactive**: Trainee is temporarily inactive
- **OnLeave**: Trainee is on approved leave

## Admin Dashboard Integration

### Frontend Implementation for Admin Profile

#### 1. Trainee Status Toggle Component
```javascript
import React, { useState } from 'react';
import { traineeService } from '../services/traineeService';

const TraineeStatusToggle = ({ trainee, onStatusUpdate }) => {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const updateStatus = async (newStatus) => {
    try {
      setLoading(true);
      setError(null);
      
      const updateData = {
        id: trainee.id,
        email: trainee.email,
        phoneNo: trainee.phoneNo,
        status: newStatus,
        bloodGroup: trainee.bloodGroup,
        aadhaarId: trainee.aadhaarId,
        healthCondition: trainee.healthCondition,
        personalInterest: trainee.personalInterest,
        address: trainee.address,
        currentAddress: trainee.currentAddress,
        contactNumber: trainee.contactNumber,
        emergencyContactName: trainee.emergencyContactName,
        emergencyContactRelationship: trainee.emergencyContactRelationship,
        emergencyContactNo: trainee.emergencyContactNo
      };
      
      const response = await traineeService.updateTrainee(trainee.id, updateData);
      
      if (response.succeeded) {
        onStatusUpdate(response.data);
        alert(`Trainee status updated to ${newStatus}`);
      } else {
        setError(response.message);
      }
    } catch (err) {
      setError('Failed to update trainee status');
      console.error(err);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="trainee-status-toggle">
      <label>Status:</label>
      <select
        value={trainee.status}
        onChange={(e) => updateStatus(e.target.value)}
        disabled={loading}
        className="status-dropdown"
      >
        <option value="Active">Active</option>
        <option value="Inactive">Inactive</option>
        <option value="OnLeave">On Leave</option>
      </select>
      
      {loading && <span className="loading-indicator">Updating...</span>}
      {error && <span className="error-message">{error}</span>}
    </div>
  );
};

export default TraineeStatusToggle;
```

#### 2. Trainee Service Integration
```javascript
// services/traineeService.js
import { api } from './apiClient';

export const traineeService = {
  // Get all trainees
  getAllTrainees: async () => {
    const response = await api.get('/Trainees');
    return response.data;
  },
  
  // Update trainee (including status)
  updateTrainee: async (id, traineeData) => {
    const response = await api.put(`/Trainees/${id}`, traineeData);
    return response.data;
  },
  
  // Quick status update helper
  updateTraineeStatus: async (id, trainee, newStatus) => {
    const updateData = {
      id: id,
      email: trainee.email,
      phoneNo: trainee.phoneNo,
      status: newStatus,
      bloodGroup: trainee.bloodGroup,
      aadhaarId: trainee.aadhaarId,
      healthCondition: trainee.healthCondition,
      personalInterest: trainee.personalInterest,
      address: trainee.address,
      currentAddress: trainee.currentAddress,
      contactNumber: trainee.contactNumber,
      emergencyContactName: trainee.emergencyContactName,
      emergencyContactRelationship: trainee.emergencyContactRelationship,
      emergencyContactNo: trainee.emergencyContactNo
    };
    
    return await traineeService.updateTrainee(id, updateData);
  }
};
```

#### 3. Admin Profile Page Example
```javascript
import React, { useState, useEffect } from 'react';
import { traineeService } from '../services/traineeService';
import TraineeStatusToggle from '../components/TraineeStatusToggle';

const AdminTraineeProfile = ({ traineeId }) => {
  const [trainee, setTrainee] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchTrainee();
  }, [traineeId]);

  const fetchTrainee = async () => {
    try {
      const response = await traineeService.getAllTrainees();
      const foundTrainee = response.data.find(t => t.id === traineeId);
      setTrainee(foundTrainee);
    } catch (error) {
      console.error('Error fetching trainee:', error);
    } finally {
      setLoading(false);
    }
  };

  const handleStatusUpdate = (updatedTrainee) => {
    setTrainee(updatedTrainee);
  };

  if (loading) return <div>Loading...</div>;
  if (!trainee) return <div>Trainee not found</div>;

  return (
    <div className="admin-trainee-profile">
      <h2>Trainee Profile</h2>
      
      <div className="profile-section">
        <h3>Basic Information</h3>
        <p><strong>Name:</strong> {trainee.username}</p>
        <p><strong>Email:</strong> {trainee.email}</p>
        <p><strong>Batch:</strong> {trainee.batchName}</p>
        
        {/* Status Toggle Component */}
        <TraineeStatusToggle 
          trainee={trainee} 
          onStatusUpdate={handleStatusUpdate}
        />
      </div>

      <div className="profile-section">
        <h3>Contact Information</h3>
        <p><strong>Phone:</strong> {trainee.phoneNo}</p>
        <p><strong>Contact Number:</strong> {trainee.contactNumber}</p>
        <p><strong>Address:</strong> {trainee.address}</p>
      </div>

      <div className="profile-section">
        <h3>Emergency Contact</h3>
        <p><strong>Name:</strong> {trainee.emergencyContactName}</p>
        <p><strong>Relationship:</strong> {trainee.emergencyContactRelationship}</p>
        <p><strong>Phone:</strong> {trainee.emergencyContactNo}</p>
      </div>
    </div>
  );
};

export default AdminTraineeProfile;
```

#### 4. Status Badge Component
```javascript
const StatusBadge = ({ status }) => {
  const getStatusColor = (status) => {
    switch (status) {
      case 'Active':
        return 'badge-success'; // Green
      case 'Inactive':
        return 'badge-danger';  // Red
      case 'OnLeave':
        return 'badge-warning'; // Orange
      default:
        return 'badge-secondary';
    }
  };

  return (
    <span className={`badge ${getStatusColor(status)}`}>
      {status}
    </span>
  );
};

// Usage in trainee list
<td><StatusBadge status={trainee.status} /></td>
```

## Validation Rules

1. **Status Field**: 
   - Required field (must be provided)
   - Must be one of: "Active", "Inactive", "OnLeave"
   - Enum validation occurs at the API level

2. **Other Fields**:
   - Email uniqueness is validated
   - Aadhaar ID uniqueness is validated (if provided)
   - All other fields are optional

## Database Updates

When status is updated:
- ? `Trainee.Status` field is updated with new value
- ? `Trainee.UpdatedAt` timestamp is set to current UTC time
- ? Changes are persisted to database
- ? Updated trainee is returned in response

## Status Codes

- **200 OK**: Status updated successfully
- **400 Bad Request**: Invalid status value or validation error
- **404 Not Found**: Trainee with specified ID not found
- **500 Internal Server Error**: Server-side error
