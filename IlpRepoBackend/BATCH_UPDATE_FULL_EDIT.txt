================================================================================
              BATCH UPDATE API - FULL EDIT CAPABILITY IMPLEMENTATION
================================================================================

## Overview
Enhanced the PUT /api/Batch/{id} endpoint to support editing all batch details 
that are available in the POST API, including batch type by ID and phases.

## Problem Statement
Previously, the PUT API only supported updating:
- BatchName
- BatchType (by name string)
- StartDate
- EndDate

It was missing:
- BatchTypeId (had to use string name instead)
- Phases collection (couldn't update phases)

This made it impossible to fully manage batches through the update API.

## Solution Implemented

**After**:

{
    public int Id { get; set; }
    public string BatchName { get; set; } = string.Empty;
    public int? BatchTypeId { get; set; }  // Changed to ID
    public DateTime? StartDate { get; set; }
    public DateTime? EndDate { get; set; }
    public List<PhaseDto> Phases { get; set; } = new List<PhaseDto>();  // Added

### Changes in UpdateBatchHandler

**File**: `IlpRepoBackend.Application\Handler\Batchs\UpdateBatchHandler.cs`

1. **Removed BatchType string handling** - Now uses BatchTypeId directly
2. **Added Phase handling** - Can now update phases
3. **Phase replacement strategy** - Clears and replaces all phases
4. **Re-fetch with includes** - Ensures response includes all related data

**Key Implementation**:
```csharp
// Update basic batch properties
existingBatch.BatchName = request.BatchName;
existingBatch.BatchTypeId = request.BatchTypeId;
existingBatch.Status = calculatedStatus;
existingBatch.StartDate = request.StartDate;
existingBatch.EndDate = request.EndDate;
existingBatch.UpdatedAt = DateTime.UtcNow;

// Handle phases update
if (request.Phases != null)
{
    // Clear existing phases
    existingBatch.Phases.Clear();

    // Add new phases
    if (request.Phases.Any())
    {
        foreach (var phaseDto in request.Phases)
        {
            var phase = new Phase
            {
                PhaseType = phaseDto.PhaseType,
                PhaseTypeId = phaseDto.PhaseTypeId,
                StartDate = phaseDto.StartDate,
                EndDate = phaseDto.EndDate,
                BatchId = existingBatch.Id,
                CreatedAt = DateTime.UtcNow,
                UpdatedAt = DateTime.UtcNow
            };
            existingBatch.Phases.Add(phase);
        }
    }
}
```

## Phase Update Behavior

### Complete Replacement Strategy
The phases are completely replaced when updating a batch:

1. **If `phases` array is provided and not empty**: 
   - All existing phases are deleted
   - New phases from the request are created

2. **If `phases` array is provided but empty `[]`**: 
   - All existing phases are deleted
   - No new phases are created

3. **If `phases` field is not provided or null**:
   - Existing phases are preserved
   - No changes to phases

## Breaking Changes

### ?? BatchType Field Removed
The `BatchType` string field has been replaced with `BatchTypeId` integer field.

**Before**:
```json

  "batchType": "Associate Software Developer"  // String name
}
```

**After**:
```json
{
  "batchTypeId": 1  // Integer ID
}
```

**Migration**: Update your frontend to use BatchTypeId instead of BatchType string.

## Frontend Integration

### Updated Service
```javascript
// services/batchService.js
import { api } from '../api/ApiClient';

export const batchService = {
  // Create batch
  createBatch: async (batchData) => {
    return await api.post('/Batch', {
      batchName: batchData.batchName,
      batchTypeId: batchData.batchTypeId,
      startDate: batchData.startDate,
      endDate: batchData.endDate,
      phases: batchData.phases
    });
  },

  // Update batch - NOW SUPPORTS SAME FIELDS AS CREATE
  updateBatch: async (id, batchData) => {
    return await api.put(`/Batch/${id}`, {
      batchName: batchData.batchName,
      batchTypeId: batchData.batchTypeId,  // Changed from batchType
      startDate: batchData.startDate,
      endDate: batchData.endDate,
      phases: batchData.phases  // Now supported!
    });
  },

  // Update batch without changing phases
  updateBatchBasicInfo: async (id, batchData) => {
    return await api.put(`/Batch/${id}`, {
      batchName: batchData.batchName,
      batchTypeId: batchData.batchTypeId,
      startDate: batchData.startDate,
      endDate: batchData.endDate
      // No phases field - existing phases preserved
    });
  }
};
```

### React Component Example
```jsx
import React, { useState, useEffect } from 'react';
import { batchService } from '../services/batchService';
import { phaseTypeService } from '../services/phaseTypeService';

const BatchForm = ({ batchId, onSaved }) => {
  const [formData, setFormData] = useState({
    batchName: '',
    batchTypeId: null,
    startDate: '',
    endDate: '',
    phases: []
  });
  const [phaseTypes, setPhaseTypes] = useState([]);
  const [loading, setLoading] = useState(false);
  const isEditMode = !!batchId;

  useEffect(() => {
    loadPhaseTypes();
    if (isEditMode) {
      loadBatch();
    }
  }, [batchId]);

  const loadPhaseTypes = async () => {
    const types = await phaseTypeService.getAllPhaseTypes();
    setPhaseTypes(types);
  };

  const loadBatch = async () => {
    const batch = await batchService.getBatchById(batchId);
    setFormData({
      batchName: batch.batchName,
      batchTypeId: batch.batchTypeId,
      startDate: batch.startDate?.split('T')[0] || '',
      endDate: batch.endDate?.split('T')[0] || '',
      phases: batch.phases || []
    });
  };

  const handleSubmit = async (e) => {
    e.preventDefault();
    setLoading(true);

    try {
      if (isEditMode) {
        await batchService.updateBatch(batchId, formData);
        alert('Batch updated successfully!');
      } else {
        await batchService.createBatch(formData);
        alert('Batch created successfully!');
      }
      onSaved();
    } catch (error) {
      alert('Error: ' + error.message);
    } finally {
      setLoading(false);
    }
  };

  const addPhase = () => {
    setFormData({
      ...formData,
      phases: [
        ...formData.phases,
        {
          phaseType: '',
          phaseTypeId: null,
          startDate: '',
          endDate: ''
        }
      ]
    });
  };

  const updatePhase = (index, field, value) => {
    const newPhases = [...formData.phases];
    newPhases[index][field] = value;
    
    if (field === 'phaseTypeId') {
      const selectedType = phaseTypes.find(pt => pt.id === parseInt(value));
      if (selectedType) {
        newPhases[index].phaseType = selectedType.name;
      }
    }
    
    setFormData({ ...formData, phases: newPhases });
  };

  const removePhase = (index) => {
    const newPhases = formData.phases.filter((_, i) => i !== index);
    setFormData({ ...formData, phases: newPhases });
  };

  return (
    <form onSubmit={handleSubmit}>
      <h2>{isEditMode ? 'Edit Batch' : 'Create Batch'}</h2>
      
      <input
        type="text"
        placeholder="Batch Name"
        value={formData.batchName}
        onChange={(e) => setFormData({...formData, batchName: e.target.value})}
        required
      />
      
      <select
        value={formData.batchTypeId || ''}
        onChange={(e) => setFormData({...formData, batchTypeId: parseInt(e.target.value)})}
        required
      >
        <option value="">Select Batch Type</option>
        {/* Assuming you fetch batch types */}
        <option value="1">Associate Software Developer</option>
        <option value="2">Senior Developer</option>
      </select>
      
      <input
        type="date"
        value={formData.startDate}
        onChange={(e) => setFormData({...formData, startDate: e.target.value})}
      />
      
      <input
        type="date"
        value={formData.endDate}
        onChange={(e) => setFormData({...formData, endDate: e.target.value})}
      />
      
      <h3>Phases</h3>
      {formData.phases.map((phase, index) => (
        <div key={index} style={{border: '1px solid #ccc', padding: '10px', margin: '10px 0'}}>
          <select
            value={phase.phaseTypeId || ''}
            onChange={(e) => updatePhase(index, 'phaseTypeId', e.target.value)}
            required
          >
            <option value="">Select Phase Type</option>
            {phaseTypes.map((pt) => (
              <option key={pt.id} value={pt.id}>{pt.name}</option>
            ))}
          </select>
          
          <input
            type="date"
            value={phase.startDate}
            onChange={(e) => updatePhase(index, 'startDate', e.target.value)}
            required
          />
          
          <input
            type="date"
            value={phase.endDate}
            onChange={(e) => updatePhase(index, 'endDate', e.target.value)}
            required
          />
          
          <button type="button" onClick={() => removePhase(index)}>
            Remove
          </button>
        </div>
      ))}
      
      <button type="button" onClick={addPhase}>Add Phase</button>
      
      <button type="submit" disabled={loading}>
        {loading ? 'Saving...' : (isEditMode ? 'Update Batch' : 'Create Batch')}
      </button>
    </form>
  );
};

export default BatchForm;
```

## Important Notes

### 1. Phase Replacement Behavior
When updating phases, ALL existing phases are replaced with the new ones. This is 
an "all or nothing" approach. If you want to keep some phases, you must include 
them in the update request.

### 2. Phase IDs in Request
The `PhaseDto` has an `Id` field, but it's not used in the update process. The 
system always creates new phase records and deletes old ones. This simplifies 
the logic but means phase IDs will change after an update.

### 3. Timestamps
- `UpdatedAt` is automatically set to current UTC time
- Each phase gets its own `CreatedAt` and `UpdatedAt` timestamps

### 4. Status Auto-Calculation
Remember that status is always auto-calculated based on dates. You cannot 
manually set the status.
