================================================================================
              DELETE BATCH - FOREIGN KEY CONSTRAINT FIX
================================================================================

## Issue Description
**Error**: "23503: update or delete on table \"batches\" violates foreign key 
constraint \"FK_trainees_batches_batch_id\" on table \"trainees\""

**Error Type**: Foreign Key Constraint Violation (PostgreSQL Error 23503)

**Location**: DeleteBatchHandler.cs - When attempting to delete a batch with 
associated trainees

## Root Cause

PostgreSQL was preventing the deletion of a batch because:
1. The batch has trainees associated with it
2. The `trainees` table has a foreign key constraint to the `batches` table
3. The constraint prevents "orphaned" trainees (trainees without a batch)

### Database Relationships:
```
Batch (1) ----< (Many) Trainee
Batch (1) ----< (Many) Phase
Batch (1) ----< (Many) TrainingSchedule
```

All three relationships have foreign key constraints that prevent deletion.

## Solution Implemented

Added **validation logic** to check for related entities before attempting 
deletion. This provides clear, user-friendly error messages instead of 
database exceptions.

### Implementation Details:

```csharp
public async Task<bool> Handle(DeleteBatchCommand request, CancellationToken cancellationToken)
{
    // 1. Check if batch exists
    var batch = await _batchRepository.GetByIdAsync(request.Id);
    if (batch == null)
    {
        throw new InvalidOperationException($"Batch with ID '{request.Id}' not found");
    }
    
    // 2. Check if batch has trainees
    var traineesInBatch = await _traineeRepository.GetByBatchIdAsync(request.Id);
    if (traineesInBatch.Any())
    {
        throw new InvalidOperationException(
            $"Cannot delete batch with ID '{request.Id}' because it has {traineesInBatch.Count()} trainee(s) associated with it. " +
            "Please remove or reassign the trainees before deleting the batch.");
    }
    
    // 3. Check if batch has phases
    if (batch.Phases != null && batch.Phases.Any())
    {
        throw new InvalidOperationException(
            $"Cannot delete batch with ID '{request.Id}' because it has {batch.Phases.Count} phase(s) associated with it. " +
            "Please remove the phases before deleting the batch.");
    }
    
    // 4. Check if batch has training schedules
    if (batch.TrainingSchedules != null && batch.TrainingSchedules.Any())
    {
        throw new InvalidOperationException(
            $"Cannot delete batch with ID '{request.Id}' because it has {batch.TrainingSchedules.Count} training schedule(s) associated with it. " +
            "Please remove the training schedules before deleting the batch.");
    }
    
    // 5. Safe to delete - no related entities
    return await _batchRepository.DeleteAsync(request.Id);
}
```

## Alternative Approaches

### Option 1: Cascade Delete (NOT Implemented)
Configure the database to automatically delete all related entities:

```csharp
// In AppDbContext.cs
entity.HasMany(b => b.Trainees)
    .WithOne(t => t.Batch)
    .HasForeignKey(t => t.BatchId)
    .OnDelete(DeleteBehavior.Cascade); // Delete trainees when batch is deleted
```

**Pros**: Simpler deletion logic
**Cons**: More dangerous - could accidentally delete lots of data

### Option 2: Soft Delete (NOT Implemented)
Add an `IsDeleted` flag instead of actually deleting:

```csharp
public class Batch
{
    public bool IsDeleted { get; set; }
    // ... other properties
}
```

**Pros**: Can recover deleted data
**Cons**: Adds complexity to all queries (must filter out deleted items)

### Option 3: Set Null (NOT Implemented)
Allow trainees to exist without a batch:

```csharp
entity.HasMany(b => b.Trainees)
    .WithOne(t => t.Batch)
    .HasForeignKey(t => t.BatchId)
    .OnDelete(DeleteBehavior.SetNull);
```

**Pros**: Doesn't break foreign keys
**Cons**: May not make business sense (trainees without batches)

## Frontend Integration

### Service Example
```javascript
// services/batchService.js
import { api } from '../api/ApiClient';

export const batchService = {
  // Delete batch with proper error handling
  deleteBatch: async (batchId) => {
    try {
      await api.delete(`/Batch/${batchId}`);
      return { success: true };
    } catch (error) {
      // Check if it's a constraint violation
      if (error.message.includes('trainee(s) associated')) {
        return {
          success: false,
          reason: 'HAS_TRAINEES',
          message: error.message
        };
      } else if (error.message.includes('phase(s) associated')) {
        return {
          success: false,
          reason: 'HAS_PHASES',
          message: error.message
        };
      } else if (error.message.includes('training schedule(s)')) {
        return {
          success: false,
          reason: 'HAS_SCHEDULES',
          message: error.message
        };
      }
      return {
        success: false,
        reason: 'UNKNOWN',
        message: error.message
      };
    }
  },
  
  // Check if batch can be deleted
  canDeleteBatch: async (batchId) => {
    try {
      const batch = await api.get(`/Batch/${batchId}`);
      
      // Check if batch has related data
      const hasTrainees = batch.trainees && batch.trainees.length > 0;
      const hasPhases = batch.phases && batch.phases.length > 0;
      const hasSchedules = batch.trainingSchedules && batch.trainingSchedules.length > 0;
      
      return {
        canDelete: !hasTrainees && !hasPhases && !hasSchedules,
        blockers: {
          trainees: hasTrainees ? batch.trainees.length : 0,
          phases: hasPhases ? batch.phases.length : 0,
          schedules: hasSchedules ? batch.trainingSchedules.length : 0
        }
      };
    } catch (error) {
      throw error;
    }
  }
};
```

### React Component Example
```jsx
import React, { useState } from 'react';
import { batchService } from '../services/batchService';

const DeleteBatchButton = ({ batchId, onDeleted }) => {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const handleDelete = async () => {
    if (!window.confirm('Are you sure you want to delete this batch?')) {
      return;
    }

    setLoading(true);
    setError(null);

    try {
      // Check if batch can be deleted
      const checkResult = await batchService.canDeleteBatch(batchId);
      
      if (!checkResult.canDelete) {
        const { trainees, phases, schedules } = checkResult.blockers;
        let message = 'Cannot delete batch:\n';
        if (trainees > 0) message += `- Has ${trainees} trainee(s)\n`;
        if (phases > 0) message += `- Has ${phases} phase(s)\n`;
        if (schedules > 0) message += `- Has ${schedules} schedule(s)\n`;
        message += '\nPlease remove these items first.';
        
        alert(message);
        return;
      }

      // Attempt deletion
      const result = await batchService.deleteBatch(batchId);
      
      if (result.success) {
        alert('Batch deleted successfully!');
        onDeleted();
      } else {
        setError(result.message);
        alert('Error: ' + result.message);
      }
    } catch (err) {
      setError(err.message);
      alert('Error: ' + err.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      <button 
        onClick={handleDelete} 
        disabled={loading}
        style={{ backgroundColor: 'red', color: 'white' }}
      >
        {loading ? 'Deleting...' : 'Delete Batch'}
      </button>
      {error && <div style={{ color: 'red', marginTop: '10px' }}>{error}</div>}
    </div>
  );
};

export default DeleteBatchButton;
```

## Database Constraint Details

### Current Foreign Key Constraints:

1. **trainees.batch_id ? batches.id**
   - Constraint: `FK_trainees_batches_batch_id`
   - Action: RESTRICT (default)
   - Prevents deletion of batch with trainees

2. **phases.batch_id ? batches.id**
   - Constraint: `FK_phases_batches_batch_id`
   - Action: CASCADE (assuming based on your config)
   - Would delete phases when batch is deleted

3. **training_schedules.batch_id ? batches.id**
   - Constraint: `FK_training_schedules_batches_batch_id`
   - Action: RESTRICT (default)
   - Prevents deletion of batch with schedules
